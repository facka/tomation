How to Run

Follow these steps to run the examples with the Tomation Chrome Extension:

  1. 1 Install and open the Tomation Chrome Extension
  2. 2 Visit this page — examples auto-load
  3. 3 Open one of the examples apps
  4. 4 Select a test from the list in the extension sidepanel and click Run

Note: Custom projects require compiling TypeScript before loading tests.
